I'm a software engineer studying computer science at the University of Queensland (UQ), where I also tutor. I mostly work on backend systems, developer tools and machine learning.

A couple of projects I'm working on:

- [better-google-colab-cli](https://github.com/CameronBadman/better-google-colab-cli) — An unofficial fork of Google's Colab CLI for running scripts and notebook cells from a terminal or coding agent. It keeps track of jobs after the command exits, so you can start work, close the terminal and return later to check progress and collect output without rerunning the job.
- [Hippocampus-1.3](https://github.com/CameronBadman/Hippocampus-1.3) — Ongoing research into graph memory and retrieval, exploring how a learned model can decide which nodes to visit when searching a graph. The current Rust implementation includes the traversal engine, model training and evaluation tools. It's still a work in progress.
